# MrChat downloads

Official Windows client installers and signed update metadata for MrChat.

Download the Windows installer from [Releases](https://github.com/runeemiljensendk-arch/MRChat-Releases/releases). Updates are optional and require your confirmation.

This repository contains client downloads only. It does not contain server software, server configuration, or application source code.

Each Windows release contains an installer, its updater signature, and windows-update.json. Updater signatures are separate from Windows publisher signing.
